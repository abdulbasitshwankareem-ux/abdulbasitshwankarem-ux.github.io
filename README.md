# AK Digital Craft — Portfolio website

A responsive static portfolio built from the supplied 8-page PDF reference.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout and styling
- `script.js` — mobile navigation toggle

## Publish with GitHub Pages (free)
1. Create a **public** repository named exactly `YOUR-USERNAME.github.io`.
2. Upload these three files (`index.html`, `style.css`, `script.js`) to the repository root.
3. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. After deployment, open `https://YOUR-USERNAME.github.io`.

Replace `YOUR-USERNAME` with your GitHub username. The portfolio text and contact details follow the provided PDF. The work cards are illustrative category visuals rather than claims of completed client projects. The LinkedIn link is a generic LinkedIn homepage; update it to your exact profile URL before publishing.
